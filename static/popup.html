Ironheights

AI skill scanner

Grades AI agent skills (any folder with a SKILL.md) before you install them: OpenClaw, Claude, Grok Bot, Codex, Cursor and any other AI bot.

Scans run inside your browser. Skill files are read as text and never run. No account, no analytics, no telemetry.

No findings is not proof of safety.
